# Superstore Sales & Profit Analysis Dashboard

## 📊 Project Overview

An interactive Excel dashboard built to analyze sales performance, profitability, product performance, discounts, returns, and customer distribution.

The project transforms transactional data into business-focused insights using Excel PivotTables, PivotCharts, calculated fields, slicers, and interactive visualizations.

## 🎯 Business Objective

The objective of this project is to provide a clear overview of business performance and identify areas that may require attention.

The analysis focuses on:

- Sales performance over time
- Orders and profitability
- Profit margin
- Category performance
- Top-performing products
- Discount impact on profit
- Return rates
- Customer concentration by region

## 📌 Dashboard KPIs

The dashboard tracks five main KPIs:

- Total Sales
- Total Orders
- Total Profit
- Profit Margin
- Total Customers
These KPIs provide a high-level overview of the business's sales, order volume, profitability, and customer base.

## 📈 Dashboard Analysis

### Sales Trend
Tracks sales performance over time and highlights changes in business activity.

### Sales & Profit by Category
Compares sales and profit across product categories.

### Sales Distribution by Category
Shows how total sales are distributed across the main product categories.

### Top 10 Products by Profit
Identifies the products generating the highest profit.

### Average Profit by Discount
Examines how average profit changes across different discount levels.

### Return Rate by State
Provides a geographic view of return rates across states.

### Return Rate by Category
Compares return rates across product categories.

### Customer Concentration by Region
Shows the distribution of customers across regions.

## 🎛️ Interactive Features

The dashboard includes interactive slicers that allow users to explore the data dynamically.

Users can filter the dashboard by available dimensions such as:

- Region
- Category

The connected KPIs and visualizations update based on the selected filters.

## 💡 Business Questions

This dashboard was designed to answer questions such as:

1. How are sales performing over time?
2. Which categories generate the most sales?
3. Which categories contribute most to profit?
4. Which products generate the highest profit?
5. How does discounting relate to average profit?
6. Which states have higher return rates?
7. Which categories have higher return rates?
8. How are customers distributed across regions?

## 🔍 Key Takeaways

The dashboard provides a structured way to identify:

- Strong and weak-performing product categories
- High-profit products
- Potential relationships between discounts and profitability
- Geographic differences in return rates
- Regional differences in customer concentration
